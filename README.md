# 📊 Sales Data Analysis – Power BI

## 📌 Project Overview

This project presents an interactive **Sales Data Analysis Dashboard developed using Microsoft Power BI**.
The objective of this project is to analyze sales performance, profitability, customers, products, regions, and orders using data visualization and business intelligence techniques.
The project demonstrates the complete process of transforming raw sales data into meaningful and interactive business insights using **Power Query, Data Modeling, DAX, and Power BI visualizations**.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze overall sales and profit performance
- Identify sales and profit trends over time
- Analyze product and category performance
- Understand customer segment performance
- Compare regional sales performance
- Analyze order and shipping information
- Identify profitable and less profitable areas
- Analyze returned orders
- Build an interactive and user-friendly Power BI dashboard
- Convert raw business data into actionable insights
